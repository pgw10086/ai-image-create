# 步骤 8：套图结果展示优化（图片预览 + 下载）

## 1. 需求背景
当前“套图结果”区域中，点击子图缩略图会直接触发下载，缺少大图预览能力。用户在进行结果检查（清晰度、构图、细节）时，需要先预览再决定下载，当前交互效率较低。

## 2. 需求目标
1. 在“套图结果”中支持点击缩略图进入大图预览。
2. 在预览态中支持当前图片下载。
3. 保留原有下载能力（单项下载、整组打包下载）。
4. 保持现有结果分组结构、状态展示与重试流程不变。

## 3. 交互与功能说明
### 3.1 入口与打开逻辑
- 位置：`app/src/components/SuiteGenerator/SuiteResultView.tsx`
- 行为：点击子项缩略图，不再直接下载，改为打开预览弹窗。
- 默认图：弹窗默认展示被点击的那一张图。

### 3.2 预览弹窗能力
- 展示当前子项名称。
- 展示“当前序号/总数”（例如 `2/4`）。
- 展示大图（`object-contain`，保证完整可见）。
- 当子项包含多张图时，提供：
  - 上一张/下一张切换按钮。
  - 底部缩略图条，支持点击切换。

### 3.3 下载能力
- 弹窗内提供“下载当前图”按钮。
- 结果卡片中的“全部下载”保留。
- 结果卡片中的单项下载按钮保留。

## 4. 验收标准
1. 点击任一套图缩略图，可稳定打开预览弹窗。
2. 预览弹窗可正确显示被点击图，并可切换同组其它图片。
3. 点击“下载当前图”会触发浏览器下载。
4. “全部下载”仍可打包下载，不受本次改动影响。
5. 套图失败项“重试”功能不受影响。

## 5. 影响范围
- 前端组件：`app/src/components/SuiteGenerator/SuiteResultView.tsx`
- 不涉及：API 参数、任务状态结构、后端接口。

## 6. 实现备注
- 使用现有 `Dialog` 组件实现预览弹窗。
- 通过本地状态维护预览图片集合与当前索引。
- 下载仍使用浏览器 `a` 标签方式触发。
