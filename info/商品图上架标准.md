1. 亚马逊 (Amazon) —— 行业标杆，要求最严
亚马逊对**主图（Main Image）**的要求极为严格，辅图相对宽松。
图片尺寸：
最长边至少 1000像素（开启缩放/Zoom功能的门槛）。
推荐尺寸：1600像素 以上（最长边）。
最大不超过 10000像素。
背景要求：
主图：必须是纯白背景（RGB值：255, 255, 255）。
辅图：可以使用生活场景图、图表，背景无强制要求。
图片比例： 推荐 1:1（正方形），虽然支持矩形，但正方形在移动端显示效果最好。
文件格式： JPEG (首选), TIFF, PNG, GIF (不支持动图)。
内容规范：
产品必须占据图片面积的 85% 以上。
主图严禁：水印、文字、Logo、边框、模特（除非是服装/配饰）、实际上不包含的配件。
2. SHEIN —— 时尚快时尚风格，强调视觉美感
SHEIN 以服装和时尚品类为主，图片风格更像时尚杂志，要求高清晰度和统一的视觉风格。
图片尺寸：
推荐尺寸：1340 x 1785 像素（这是最标准的竖图比例）。
或者 3:4 的纵向比例。
背景要求：
通常要求纯色背景（白色或浅灰色），或干净的实景背景。
非服装类（如家居）：可以使用纯白背景。
内容规范：
服装类： 通常不能出现模特的脸（部分供应商要求“无头照”或截头），或者使用“鬼模图”（隐形模特/平铺）。
严禁水印、非品牌Logo。
图片必须清晰，无噪点，色彩还原度高。
注意： SHEIN 这种自营/半托管模式，往往对供应商提供的图有审美上的审核，不仅仅是参数达标。
3. Temu —— 拼多多海外版，审核严格
Temu 对图片的审核非常细致，特别反感国内电商常见的“牛皮癣”文字。
图片尺寸：
主图比例必须是 1:1（正方形）。
尺寸：至少 800 x 800 像素，推荐 1600 x 1600 像素。
背景要求：
推荐纯白背景或干净的实景。
内容规范：
严禁中文： 图片中绝对不能出现中文字符。
严禁牛皮癣： 主图不能有促销贴纸、边框、大面积文字描述。
实物必须清晰，不能过度P图导致失真。
如果是服装，要求模特图必须拥有版权，严禁盗图。
4. TikTok Shop —— 社交电商，注重原生感
TikTok 的图片需要适应手机竖屏浏览习惯，同时也需要正方形的产品卡片图。
图片尺寸：
主图：1:1（正方形），至少 600 x 600 像素，推荐 1200 x 1200 像素。
详情页/营销图：支持 3:4 或 9:16 竖屏比例。
背景要求：
主图建议纯白或干净背景，以便系统抓取。
内容规范：
文件大小通常限制在 5MB 以内。
不仅要有白底图，强烈建议上传带有“生活方式”感（Lifestyle）的场景图，以提高转化。
5. 速卖通 (AliExpress)
图片尺寸：
推荐 1000 x 1000 像素 或以上。
比例：1:1。
背景要求：
主图建议白底。
内容规范：
现在也越来越趋向于亚马逊化，不鼓励过多的文字遮挡。
支持上传主图视频。
6. eBay
图片尺寸：
最长边至少 500 像素（否则会被系统拦截）。
推荐 1600 像素。
背景要求：
推荐白色或中性背景。
内容规范：
严禁： 图片中添加任何文字、边框、Logo水印（这是eBay非常严格的规定）。
不能使用“暂无图片”的占位符。
7. Shopee / Lazada (东南亚巨头)
图片尺寸：
Shopee: 至少 500 x 500 px，推荐 1024 x 1024 px。
Lazada: 至少 500 x 500 px，推荐 800 x 800 px 或更高。
背景要求：
推荐白底，但也接受场景图作为主图（东南亚市场对促销文字容忍度稍高，但白底图权重更高）。
特殊点：
Shopee 允许在主图中添加简短的促销边框或Logo（根据大促活动而定），但建议保持第一张图干净。
