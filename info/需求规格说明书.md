# 需求规格说明书（SRS）- 电商 AI 商品图生成工作台

## 1. 项目概述
本项目旨在构建一个面向电商场景的 AI 商品图生成工作台。用户通过文本描述、上传参考图、或使用“智能布局画布”进行多素材组合，生成用于商品详情页/主图的素材图片。当前阶段以“完成核心功能”为目标，并为后续 Skills 定制能力预留扩展点。

## 2. 参考文档
* API Curl 示例：`info/模型curl调用.md`
* Seedream 图片生成 API 文档：`info/图片生成 API（Seedream 4.0-4.5 API）.md`
* 分步实现说明：`info/step/`

## 3. 范围说明
### 3.1 本期范围（必须做）
* 自由生成（文生图 / 图生图 / 多图参考）
* 商品套图模版（应用层编排，每张图独立 Prompt）
* 智能布局画布（画框定位 + 素材拼贴 + 语义分割占位 + 参考图组合生成）

### 3.2 本期暂缓（先写入文档，暂不实现）
* 针对特定电商平台的“强规则校验/自动合规审查”（后续 Skills 定制）

### 3.3 暂不做（明确不实现或后期迭代）
* 针对特定电商平台的“强规则校验/自动合规审查”（Skills 定制）
* 局部重绘/蒙版编辑（API 文档中未提供 Mask 参数，不在本期范围）
* 自动翻译（不接入翻译/LLM 服务时不保证语义等价，仅通过 Prompt 约束）

#### 4.1.1 顶部“参数条”与 API 映射（必须实现）
“全局生成上下文”（Global Generation Context）必须可被 API 消费或可确定性地映射为 API 入参/Prompt 模板；禁止只做 UI 选中态。

实现形态要求：
1. **自由生成（单图）**：使用顶部参数条承载全局上下文。
2. **套图模式**：全局上下文应聚合在“全局商品描述”卡片内部（与输入同区），避免额外悬浮/重复入口。

| 顶部参数项（示例） | 语义字段（建议） | 对 API 的映射方式 | 备注 |
|---|---|---|---|
| 跨境设计 | `scene='crossborder'` | 主要映射为 Prompt 模板/平台规则后缀 | 不直接对应单一 API 字段 |
| 详情图 | `scene='detail'` | Prompt 模板 +（可选）组图：`sequential_image_generation='auto'` + `max_images` | 组图仅 4.0/4.5 支持；智能布局固定单图 |
| 模型版本（如“泰豪生图1.0”） | `modelPreset` | `model` | 需映射到具体 Model/Endpoint ID（如 `doubao-seedream-4-5-251128`） |
| 张数（如“6张/8张”） | `imageCount` | 组图：`sequential_image_generation='auto'` + `sequential_image_generation_options.max_images=imageCount` | 需满足：参考图数量 + 生成数量 ≤ 15；超出需自动截断 |
| 平台（Amazon 等） | `platformId` | Prompt 规则后缀 | 本期不做强合规审查，仅通过 Prompt 约束输出倾向 |
| 语言（英文/中文） | `language='en'|'zh'` | Prompt 约束（例如 “Use English descriptions.”） | 不依赖翻译服务时仅约束输出语言，不承诺等价翻译 |
| 画面比例 | `ratioMode` | Prompt 尺寸/比例提示 +（可选）推荐像素 | 比例与尺寸解耦；比例只决定推荐值与提示词，不直接等于 `size` |
| 输出尺寸模式 | `sizeMode` | `size` | `sizeMode=resolution`：`1K/2K/4K`（按模型限制）；`sizeMode=pixels`：`宽x高` |
| 输出尺寸输入 | `size` | `size` | 像素尺寸需校验/归一化，遵循 API 文档的总像素与最小像素门槛 |
| 参考风格 | `stylePreset` | Prompt 风格预设片段（文本） | 本期默认走文本预设，不占用参考图配额 |
| 上传文件 | `uploadedImages[]` | 上传后写入 `image` | 点击“上传文件”直接打开文件选择器；同一份上传列表在单图/套图共享 |
| 有文本 | `allowText` | Prompt 策略 | 勾选后提示模型生成清晰可读文案；不保证 100%可控 |
| 添加水印 | `watermark` | `watermark` | 作为可选项；当启用平台上架标准且平台不允许水印时必须强制关闭 |

#### 4.1.2 下方“能力卡片”对上方参数条的联动（必须实现）
下方红框区域不是固定展示“所有功能入口”，而是对当前全局上下文的“推荐/快捷预设”。需要实现双向联动：

1. **上方参数条 -> 下方能力卡片**：根据当前 `scene/platform/language/modelPreset/imageCount/stylePreset` 等组合，计算推荐卡片列表与默认选中卡片。
2. **下方能力卡片 -> 上方参数条**：点击某个卡片会自动设置/修正上方参数条（填补必要参数、互斥项自动切换），并切换到对应的工作模式（自由生成/智能布局等）。

补充：当能力卡片目标是“套图批量生成”时，点击应当：
* 自动切换到套图模式；
* 自动应用一个套图预设（Preset），包括：选择套图模板、设置场景/风格、并将“策略后缀”写入子项提示词（中文，可编辑）。

建议以“预设（Preset）”的方式定义能力卡片：

| 卡片 | presetId | 自动设置的顶部参数（示例） | 说明 |
|---|---|---|---|
| 详情页 | `preset_detail` | `scene=detail`、`imageCount=6`、`ratioMode=smart`、`platform=amazon?` | 面向“批量生成/多张变体” |
| 品牌模型 | `preset_brand` | `stylePreset=brand`、`language=zh/en`、`ratioMode=smart` | 面向“风格统一/品牌视觉” |

### 4.2 智能布局画布 (Smart Layout Canvas) - **核心特性**
**目标**：让用户用“画框”表达空间布局与素材归属，并将“布局信息 + 材质信息”一并喂给模型，提高组合生成成功率。

#### 4.2.1 两种工作模式
1. **素材组合模式（推荐默认）**：用户在画框中上传图片素材，同时填写/自动生成 Prompt；系统把所有素材图与布局合成图一起提交给 API。
2. **纯语义布局模式（无图片）**：用户仅画框 + 提示词；系统生成纯色块（语义分割）布局图，依靠不同框的 Prompt 与颜色占位生成最终图。

#### 4.2.2 布局合成图的两种渲染风格（用户可切换）
1. **贴图布局图（Collage）**：在 `layoutSketch` 中把 Zone 的素材图按位置贴上去；没有素材图的 Zone 用语义色块占位。
2. **纯色布局图（Segmentation）**：`layoutSketch` 中只绘制语义色块，不贴任何素材图；但仍会把所有 Zone 的原始素材图作为 `image[1..]` 传给 API。

默认：贴图布局图（Collage）。

#### 4.2.3 功能模块
| 功能模块 | 功能名称 | 详细描述 | 说明 |
|---|---|---|---|
| 区域管理 | 画框（Zone）创建/编辑 | 画布上创建多个矩形框，支持移动、缩放、层级（zIndex）。 | 画框用于“标注位置”，不是最终输出 UI |
| 区域管理 | 类型与语义颜色 | 每个 Zone 选择类型（background/prop/main），系统绑定语义颜色（例如灰/绿/红）。 | 语义颜色用于生成布局图 |
| 区域管理 | 草图区分色（sketchColor） | 当同类型存在多个 Zone 时，为每个 Zone 分配高区分度色块颜色，用于布局草图与 Prompt 标注，帮助模型区分多个区域。 | 用于 Segmentation 草图与提示词 `color=` |
| 素材管理 | Zone 素材上传 | Zone 可上传图片，作为“材质与细节参考”。 | 上传图片不会直接当最终图使用 |
| 素材管理 | 素材库与复用 | Zone 的参考图片改为绑定“素材库资源”，同一张素材图可被多个 Zone 复用，无需重复上传。 | 复用不应重复占用参考图编号 |
| 文案辅助 | 图片反推 Prompt（Caption） | 上传图片后（可选）调用视觉模型生成描述，填入 Prompt，用户可编辑。 | 可先做 Mock，后续接入真实视觉模型 |
| 文案辅助 | 提示词一键优化 | 在区域提示词输入旁提供“优化”按钮，一键优化当前区域提示词并支持撤销。 | 本期前端直连 GLM-5（Key 需自行配置） |
| 合成逻辑 | 布局合成图（layoutSketch） | 生成一张 Base64 图：用户可选择“贴图布局图/纯色布局图”。 | 该图用于强空间约束 |
| 生成执行 | 多图参考强控生成 | 请求时 `image` 数组：`[layoutSketch, ...所有 Zone 原始 refImage]`；`prompt` 为组合 Prompt。 | layoutSketch 是第一参考图 |
| 交互确认 | 预览确认与提示词编辑 | 预览弹窗展示最终提交草图/预览草图，并允许用户编辑 `GLOBAL_PROMPT` 与最终 `prompt`。 | 生成请求必须使用用户编辑后的最终 prompt |
| 交互确认 | 风格变体生成 | 基于同一布局与同一参考图集合，一键生成多种风格变体（例如 3 种），无需为不同风格重复上传同一素材图。 | 变体主要通过 GLOBAL_PROMPT/风格段落差异实现 |

#### 4.2.3.1 界面布局与降噪（Smart Layout UI）
* 智能布局页默认不展示全局积分/credits（避免右上角干扰信息）。
* 右侧面板为主要信息承载区，采用 Tab 切换：
  * **区域**：选中 Zone 时显示区域配置；未选中时展示可点击的 Zone 列表。
  * **文案**：集中填写文案变量，并在生成/预览中自动替换；面板按区域提示词占位符动态展示（并保留已填写非空项）。
* 右侧面板支持一键收起/展开，最大化画布可视面积。
* 工具栏保留高频动作（画框模式/画布尺寸/预览/生成/清空/查看结果），其余开关收纳至“高级”下拉（例如：预览贴图、REGION、DEPTH、右侧面板显示）。
* 提供“专注模式”切换：隐藏 Header / 主 Tabs / FeatureTags / Presets / Footer，仅保留智能布局画布与工具栏，便于沉浸式编辑布局。
* 智能布局页应优先使用全宽布局（取消内容区 max-width 限制或在大屏居中），避免主画布被挤到左侧、右侧出现大块空白。
* Zone 的参考图片选择支持“上传新图片 / 从素材库选择”，实现跨区域复用同一素材图。
* 预览弹窗支持“风格变体”一键生成：同一素材与布局，生成多种风格结果，结果按风格分组展示。
* **保存与复用（必须实现）**：
  * **草稿自动保存**：用户编辑画布时自动保存草稿（防刷新/误关闭丢失）；进入智能布局页时若检测到草稿，应提示“恢复/放弃”，并可手动清除草稿。
  * **画布模板库**：用户可将当前画布保存为模板（可命名/覆盖保存），并在“模板库”中一键应用以复用布局。
  * **导入/导出**：支持导出单个模板与导出全部模板为 JSON；支持从 JSON 导入模板库（用于跨环境迁移/分享）。\n    导入成功后应保证可见反馈（自动应用或打开模板库定位到最新导入项），避免“导入成功但画布空白”的误解。
*   **存储策略**：本期优先本地存储；生成历史优先落 IndexedDB（更稳，避免 localStorage 配额问题），草稿/模板/文案变量/设置使用 localStorage；如遇容量不足导致写入失败，应有明确提示，并允许降级（例如移除模板预览图以确保落盘）。

#### 4.2.4 关键约束
* API 参考图数量限制：最多 14 张参考图（需预留 1 张给 `layoutSketch`，因此 Zone 素材图建议最多 13 张）。
* 合成图中尽量避免“边框线条”与大段文本，优先使用纯色块/贴图，减少模型把边框当成画面元素的概率。
* 当素材图超过 13 张时：只保留 main/prop 类型的素材图；同类型按 zIndex 从高到低截断；background 素材图优先丢弃。
* 同类型多区域时：必须通过 `sketchColor` 提升布局草图区分度，并在 Prompt 中明确 `color=` 与 Region 编号，降低模型串区风险。

#### 4.2.5 提升位置理解的“绝杀三件套”（必须写入实现）
智能布局的常见失败是：模型无法稳定理解“哪个物体应该放在哪个区域”，或出现“串色/串属性”“嵌入/漂浮”等问题。为提升成功率，需要在现有 `layoutSketch + 多参考图` 的基础上增加三类结构化约束：

1. **区域提示（Region Prompter / Area Prompting）概念**\n
   - **目标**：将“每个 Zone 的提示词”从总 Prompt 中拆出来，形成可计算、可扩展的结构化数据。\n
   - **实现分级**：\n
     - **当前默认（Seedream API 兼容）**：不要求后端真做像素级区域生成，但必须在最终 Prompt 中输出一个结构化的 `REGION_PROMPTS` 段落，包含每个区域的 bbox 与描述。\n
     - **后端增强（可选）**：当后端接入支持区域控制的生成管线（例如 SD/ComfyUI 的 Area Prompting / Region Control）时，直接使用 `REGION_PROMPTS` 在像素区域内分别控制生成，彻底解决属性串味。\n

2. **像素坐标 + 方位 + 坐标系声明三重约束（必须）**\n
   - 对每个 Zone 输出（用于 REGION_PROMPTS）：\n
     - `BBox(px)=(x,y,w,h)`（像素，取整）\n
     - `locationHint`（如 Center-Left/Top-Right）\n
     - `color`（使用 `sketchColor`，用于区分同类型多区域）\n
     - `AnchorPx`（确定性锚点坐标，用于对齐放置）\n
   - 同时输出全局 `COORDINATE_SYSTEM` 段落，明确 x/y/z 轴规则并要求模型严格遵循。\n

3. **遮挡/深度树（Occlusion / Depth Order Tree）**\n
   - 树形结构不用于定位置，而用于定遮挡与前后关系。\n
   - 必须在 Prompt 中明确：哪些层在前、哪些层在后，以及“主体覆盖道具边缘”“禁止漂浮”等规则，降低嵌入/漂浮。\n

#### 4.2.6 智能布局的标准化输出（前端必须产出）
无论当前后端是否支持真正的区域提示，前端都必须产出下列结构化内容，供 Step 4 组合为 API 请求或供未来后端增强直接消费：

* `GLOBAL_PROMPT`：只描述整体摄影棚/光照/镜头/风格，不包含具体区域位置；允许用户在预览弹窗中编辑。\n
* `COORDINATE_SYSTEM`：明确 x/y（像素）与 z（zIndex 深度）规则，包含 `CanvasSize` 与 `AnchorRatios`。\n
* `REGION_PROMPTS[]`：每个 Zone 一条，字段至少包含：`regionNo/id/type/zIndex/locationHint/bbox(px)/prompt/autoCaption/hasReferenceImage`，并在最终文本中标注 `color(sketchColor)`、`AnchorPx`、`Margins/Padding`。\n
* `DEPTH_TREE`：按 zIndex 与 type 生成的遮挡树描述。\n
* `layoutSketch`：布局合成图（贴图/纯色），用于强空间约束。\n
* `referenceImages[]`：所有 Zone 的原始素材图（截断后），用于材质细节约束。\n
* `IMAGE_REFERENCES`：明确图号映射：`图1=layoutSketch`，`图2..=referenceImages[]`，并在各 Region 行引用“参考图：图N”。\n

### 4.3 商品套图模版 (Product Suite Templates)
**定义**：商品套图是应用层的“多次生成编排”。每张图都有独立的 Prompt（例如主图/侧视/细节/场景），从而避免 API 原生组图“多张变体但语义雷同”的局限。

| 功能模块 | 功能名称 | 详细描述 | 说明 |
|---|---|---|---|
| 模版库 | 预置模版列表 | 提供若干套图模版（鞋靴、3C、详情页、品牌视觉等）。 | 模版可配置、可扩展 |
| 模版执行 | 批量生成 | 输入全局商品描述 +（可选）参考图，系统为每个子项派生 Prompt 并逐项生成。 | 每个子项可配置张数；可使用组图能力一次返回多张 |
| 一致性策略 | 统一风格 | 同一套图共用风格后缀（灯光、背景、摄影风格）。 | 先采用 Prompt 统一 |
| 一致性策略 | 首图参考（可选） | 先生成第一张主图，再将主图作为后续图的参考图，提高主体一致性。 | 与 API 多图参考结合 |
| 镜头编辑 | 镜头清单编辑器 | 镜头类型可勾选（默认镜头集），并支持新增/删除/排序、重复添加同镜头。 | 支持自定义镜头（本地） |
| 子项配置 | 比例/尺寸/张数 | 每个子项独立配置画面比例、输出尺寸模式（分辨率档位/像素宽高）、张数。 | 尺寸需遵循 API 文档限制并自动归一化 |
| 平台规则 | 上架标准（可选） | 可选择平台上架标准（Amazon/Temu/TikTok 等），通过 Prompt 规则影响生成倾向。 | 不做强合规审查，仅做软约束 |
| 结果交付 | 分组展示 | 结果按“套图任务”分组展示，子项内支持多张缩略图展示与下载。 | 支持打包下载（JSZip） |

### 4.4 扩展能力 (Skills & Customization)（后期迭代）
* 面向站点的规则预设（尺寸、留白、背景、合规性）与流程编排。

## 5. 业务流程 (User Flow)

### 5.1 自由生成流程（单图）
1. 用户进入“自由生成”模式。
2. 输入 Prompt；可选上传 0~N 张参考图。
3. 选择输出尺寸/比例。
4. 点击生成，展示 Loading。
5. 成功：展示结果，支持预览/下载；失败：展示错误与重试按钮。

### 5.2 智能布局生成流程（素材组合模式）
1. 用户进入“智能布局”模式。
2. （可选）开启专注模式以最大化画布；需要时展开右侧面板进行区域配置与填写文案变量。
3. 在画布上画多个 Zone，并为每个 Zone 选择类型（background/prop/main）。
4. 对于需要参考的 Zone 上传图片；系统自动生成 `autoCaption` 并写入 Prompt（用户可编辑）。
5. 用户选择“布局合成图渲染风格”：贴图布局图（默认）或纯色布局图。
6. 用户点击“预览合成”，在预览弹窗中切换查看“最终提交草图 / 预览草图”，并校对参考图编号（图2起）。
7. 用户可在预览弹窗编辑 `GLOBAL_PROMPT` 与最终 `prompt`（结构化段落 + 规则）。
8. 用户点击“生成”：\n   - `image[0]` 传 `layoutSketch`（空间约束，图1）\n   - `image[1..]` 传所有 Zone 的原始 `refImage`（材质约束，图2..）\n   - `prompt` 传用户确认后的最终提示词\n9. 成功：展示成品图并保留布局以便继续微调；失败：提示错误并允许重试。

### 5.3 智能布局生成流程（纯语义布局模式）
1. 用户画多个 Zone，但不上传图片，仅填写 Prompt。\n2. 系统生成纯色块布局图（语义分割）。\n3. 使用 `image=[layoutSketch]` + 组合 Prompt 生成最终图。

### 5.4 商品套图生成流程
1. 用户进入“套图”模式，选择一个模版（或点击能力卡片一键应用预设）。
2. 在“全局商品描述”卡片输入商品描述；可选上传参考图；配置模型/风格/平台规则/水印/是否允许文字。
3. 在“镜头类型”区域勾选默认镜头集，并可新增/删除/排序/重复添加；也可创建自定义镜头。
4. 对每个子项配置画面比例、输出尺寸模式与具体尺寸、张数；系统展示每个子项的最终提交 Prompt（中文，可编辑 promptBase）。
5. 点击“开始生成”，界面展示每个子项进度；失败项可重试；支持追加生成并把图片并入该子项结果。
6. 结果按套图任务分组展示，子项内多张缩略图可直接下载；支持打包下载。

**默认内置模板库**
*   默认模板以 JSON 形式随前端打包，启动时自动导入/合并到本地模板库（localStorage）。默认模板文件位于：`app/src/default-smart-layout-templates/`。
*   默认模板的导入标记会随 JSON 内容变化自动变化（基于 raw 内容 hash 生成 sourceId），因此默认模板 JSON 更新后无需手动清理本地缓存即可看到最新内置模板。
*   更新合并策略：若本地同 id 模板仍是内置模板（`origin === 'default'`），允许原位更新；若为用户模板/导入模板/未知来源且内容不同，则不覆盖，新增一条“（内置更新）”模板以保证最新可见且不丢用户数据。
*   当前内置样例覆盖：家居（香薰蜡烛/抱枕/桌面收纳盒/陶瓷花瓶）、发饰（抓夹/发箍/大肠发圈/珍珠一字夹套装）等，用于提供“可直接应用”的参考画布。
*   能力展示型复杂模板（节选）：遮挡叠层×多参考图（双主体+四特写/三主体阶梯台座+四特写/右侧主舞台+左栏四特写/双主体错位叠放+环绕四特写），用于展示多参考图绑定与深度遮挡能力。
*   为避免本地存储超限，默认样例通常不携带 `snapshotDataUrl`；如需缩略图预览，可在模板库中应用后再“保存当前为模板”生成预览图。
